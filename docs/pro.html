Math Snap PRO

כל הכלים שעוזרים להבין ולהתכונן למבחן. משלמים פעם אחת כאן, ו-PRO עובד בכל המכשירים שלכם: אנדרואיד, מחשב ואתר.

מה יש ב-PRO

  • למה עושים כל שלבהסבר במילים פשוטות לכל צעד בפתרון
  • הוכחות בגאומטריהטבלת טענה ונימוק, כמו שהמורה רוצה
  • לימוד למבחןמעלים PDF או תמונות, ומתרגלים לפי הנושאים שבו
  • תרגולתרגילים דומים עם בדיקה ופתרון מלא
  • בדיקת הפתרון שליכותבים את הדרך, והאפליקציה מראה איפה הטעות
  • שמירה כ-PDF, עיצובים והיסטוריהשומרים פתרונות, בוחרים צבעים, ורואים הכל בכל מכשיר

קנייה

התשלום ייפתח בקרוב

התשלום מאובטח ונעשה בדף התשלום של Paylink. אחרי התשלום מקבלים במייל קוד PRO.

איך זה עובד

  1. מתחברים לחשבון באפליקציהבתפריט ☰ ← שלי ← התחברות. ה-PRO נשמר בחשבון, לא במכשיר.
  2. משלמים כאן באתרבכפתור למעלה. כדאי לכתוב בתשלום את אותו מייל של החשבון.
  3. מקבלים קוד במייל ומקלידים אותובאפליקציה: ☰ ← Math Snap PRO ← "יש לכם קוד Pro?". הקוד נראה כך: ABCD-EFGH-JKLM.
  4. זהו, PRO פעיל בכל המכשיריםבכל מכשיר שמתחברים בו לאותו חשבון.

שאלות

יש לי את האפליקציה מ-Google Play. זה עובד גם שם?

כן. מתחברים לאותו חשבון ומקלידים את הקוד במסך ה-PRO.

כמה זמן לוקח לקבל את הקוד?

בדרך כלל באותו יום. אם לא הגיע, בדקו בתיקיית הספאם או כתבו לנו בשרת הדיסקורד.

אפשר להשתמש בקוד יותר מפעם אחת?

לא. כל קוד עובד פעם אחת, לחשבון אחד. החשבון עצמו עובד בכל המכשירים שלכם.
