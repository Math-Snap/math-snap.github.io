# קריאה חכמה ב-Math Snap: מדריך הפעלה (להורה)

הקריאה החכמה שולחת תמונה של תרגיל למודל בינה מלאכותית של גוגל (Gemini), והוא מעתיק את התרגיל כטקסט. הוא קורא כתב יד, עברית, שברים, חזקות ופרטים מתוך שרטוטים. האפליקציה פותרת את התרגיל בעצמה, והמודל רק קורא את התמונה.

המפתח של גוגל לא נמצא באפליקציה. הוא שמור בשרת קטן משלנו ב-Cloudflare, שבודק שהבקשה מגיעה ממשתמש מחובר ומגביל כמה תמונות כל משתמש שולח ביום. בלי ההגדרות האלה האפליקציה עובדת כרגיל וקוראת תמונות בתוך הטלפון.

## מה צריך
- חשבון Google של מבוגר בגיל 18 ומעלה, עם אמצעי תשלום ב-Google AI Studio. העלות היא בערך אגורה עד שתיים לכל 10 תמונות, לפי המחירון של גוגל.
- חשבון Cloudflare חינמי.

## שלבים
1. **מפתח AI:** נכנסים ל-https://aistudio.google.com, יוצרים API key ומעתיקים אותו. **אל תשלחו את המפתח לאף אחד.** הוא עובר רק לשלב 3.
2. **Worker ב-Cloudflare:** ב-https://dash.cloudflare.com נכנסים ל-Workers & Pages, לוחצים Create ואז Create Worker, ונותנים לו את השם `mathsnap-read`. אחרי Deploy נכנסים ל-Edit code, מדביקים את כל התוכן של `worker.js` מהתיקייה הזאת, ולוחצים Deploy.
3. **הסוד:** בדף של ה-Worker נכנסים ל-Settings ואז ל-Variables and Secrets ולוחצים Add. בוחרים Secret, השם הוא `GEMINI_API_KEY` והערך הוא המפתח משלב 1.
4. **הגבלה יומית (מומלץ):** נכנסים ל-Storage ואז ל-KV, לוחצים Create ונותנים את השם `READS`. אחרי זה, ב-Worker, נכנסים ל-Settings ואז ל-Bindings ולוחצים Add. בוחרים KV namespace, השם הוא `READS` והמאגר הוא READS. ברירת המחדל היא 40 תמונות לחשבון ביום, ואפשר לשנות אותה עם המשתנה `DAILY_LIMIT`.
5. **הכתובת:** מעתיקים את הכתובת של ה-Worker. היא נראית כמו `https://mathsnap-read.<שם>.workers.dev`. **הכתובת היא לא סוד**, ואפשר לשלוח אותה לאיתן. הוא מכניס אותה ל-`SERVER` בקובץ `app/src/main/assets/smartread.js`, ומפרסם גרסה חדשה.

## מה כדאי לדעת
- **מי מקבל את זה:** רק משתמשי PRO מחוברים, עם אינטרנט. כל השאר ממשיכים עם הקריאה בטלפון.
- **פרטיות:** התמונה עוברת דרך השרת שלנו אל Google לקריאה, ולא נשמרת אצלנו. צריך לכתוב את זה במדיניות הפרטיות לפני שמפעילים, ובחשבון תשלום של גוגל התמונות לא משמשות לאימון המודלים שלהם.
- **אם גוגל מחליפה דגם:** קובעים את המשתנה `MODEL` לשם הדגם החדש, למשל `gemini-2.5-flash`. אין צורך לשנות קוד.
- **עצירה מיידית:** מוחקים את הסוד `GEMINI_API_KEY`. השרת יחזיר "not_set_up", והאפליקציה תחזור לבד לקריאה בטלפון.
